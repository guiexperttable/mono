Static maxScrollHeightInPx

maxScrollHeightInPx: number = 8_000_000

Maximum height (px) of the scrollable content wrapper. Taller tables are scrolled proportionally (rendering is based on the scroll factor anyway): browsers clamp element heights (Chrome ~33.5 million px) and GPU rasterization loses precision long before (1px borders disappear and text jitters beyond ~16.7 million px). 8 million px keep sub-pixel precision.

Inherited from EleScope.maxScrollHeightInPx
