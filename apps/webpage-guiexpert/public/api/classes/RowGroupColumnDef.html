Class RowGroupColumnDef

The group column of a row grouping: arrows, indentation and the group labels ("Nord (3)"). Created by RowGroupFactory.createTableModel; the column is sortable (by group key) and not editable. Its property is RowGroupColumnDef.PROPERTY – sort and state refer to it like to any column.

Example

const tableModel = RowGroupFactory.createTableModel<Sale>({ rows: sales, columnDefs, groupBy: ["region"] });
const groupColumn = tableModel.getColumnDefs()?.find(isRowGroupColumnDef);

1.1.94

Optional rowDrag

rowDrag?: RowDragColumnOption

Row drag: the body cells of this column get a drag handle (true, or a function that decides per row – e.g. no handle for locked rows). Dragging the handle moves the row (see TableOptionsIf.rowDragOptions); the keyboard alternative is Ctrl+Alt+↑/↓. TableFactory.createTableModel({ rows, rowDrag: true }) sets it on the first data column.

Example

ColumnDef.create({ property: "title", headerLabel: "Task", rowDrag: (task: { locked: boolean }) => !task.locked })
