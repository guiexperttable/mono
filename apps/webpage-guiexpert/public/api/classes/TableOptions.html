Class TableOptions

All default options of a table – see TableOptionsIf for the meaning of each field.

Use it with the spread pattern: all defaults, plus your changes.

Example

const tableOptions: TableOptionsIf = {
  ...new TableOptions(),
  hoverColumnVisible: false,
  verticalBorderVisible: false,
  defaultRowHeights: { header: 40, body: 30, footer: 36 },
  externalFilterFunction: (order: Order) => order.total > 1000
};

externalFilterFunction

externalFilterFunction: undefined | FilterFunction<any> = undefined

Your filter: called for every row, return true to show it. After changing the filter criteria call TableApi.externalFilterChanged – the table filters again and keeps the sort order.

Example

const filter = { text: "" };
const tableOptions: TableOptionsIf = {
  ...new TableOptions(),
  externalFilterFunction: (order: Order) => order.customer.toLowerCase().includes(filter.text)
};
searchInput.addEventListener("input", () => {
  filter.text = searchInput.value.toLowerCase();
  tableApi.externalFilterChanged();
});

Optional fillHandle

fillHandle?: boolean | Partial<FillHandleOptionsIf> = undefined

The fill handle: a small square at the bottom right corner of the selected range. Dragging it fills the neighbouring cells (copy, or a series: 1, 2, 3 …, dates, Item 1 → Item 2); ⌥/Alt switches between series and copy. Keyboard: Ctrl/⌘+D fills down, Ctrl/⌘+R fills right. Needs a selection model of the type "range"; only editable cells are filled. true = defaults (FillHandleOptions).

Example

const selectionModel = new SelectionModel("range", "multi");   // one model – not a new one per call
const tableOptions: TableOptionsIf = {
  ...new TableOptions(),
  getSelectionModel: () => selectionModel,
  fillHandle: true,
};

Since

1.1.96

Optional masterDetail

masterDetail?: Partial<MasterDetailOptionsIf<any>> = undefined

Master/detail: master rows get an expand icon; below an expanded row a detail row over the full width shows any content (a nested table, a form, a framework component – see MasterDetailOptionsIf). Only for flat body models. Fields you leave out keep their default (MasterDetailOptions); detailRenderer is required.

Example

const tableOptions: TableOptionsIf = {
  ...new TableOptions(),

    detailHeight: "auto",
    detailRenderer: (container, row) => { container.textContent = `Notes: ${row.notes}`; }

};
