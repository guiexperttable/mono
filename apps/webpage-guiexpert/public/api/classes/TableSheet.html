Class TableSheet

The cell formulas of a table (TableOptionsIf.cellFormulas): connects the body model with a SheetEngine. Rows are the physical rows (getAllRows() / the array), columns the data columns (row number and checkbox columns don't count). The body asks it for the value of every text input (SheetCellsIf); the table reports every write (cellsWritten). A new rows array (setRows), another row count or other columns rebuild the engine.

1.1.99
