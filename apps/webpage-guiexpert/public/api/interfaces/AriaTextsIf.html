Interface AriaTextsIf

The texts the table speaks to screen reader users: announcements of the live region (sorting, filter, copy, select all) and the accessible names of controls the table renders (row checkboxes, header group toggles).

The defaults are English (AriaTexts). Override single functions – e.g. for another language – with TableOptionsIf.ariaTexts; the others keep their default.

Every function returns plain text. It is written with textContent / setAttribute, never as HTML, so data in it (column labels, group labels) needs no escaping.

Example

const tableOptions: TableOptionsIf = {
  ...new TableOptions(),
  ariaTexts: {
    filtered: (rowCount: number) => `${rowCount} Zeilen`,
    sorted: (column: string, state: SortState) => state ? `Sortiert nach ${column}` : `Sortierung entfernt`,
  },
};

1.1.91
