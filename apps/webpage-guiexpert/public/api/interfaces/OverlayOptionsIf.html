Interface OverlayOptionsIf

Texts and behaviour of the overlays over the table body: "Loading…" (TableApi.showLoadingOverlay), "No rows to show" (empty body) and "No matching rows" (the external filter hides all rows).

Set it with TableOptionsIf.overlayOptions – every field is optional there, missing ones keep their default (OverlayOptions). The overlays are plain HTML and CSS (spinner: @keyframes), colours come from the CSS variables --ge-table-overlay-bg, --ge-table-overlay-color, --ge-table-spinner-color, --ge-table-spinner-track-color and --ge-table-spinner-size.

Example

const tableOptions: TableOptionsIf = {
  ...new TableOptions(),
  overlayOptions: {
    loadingText: "Lädt…",
    noRowsText: "Keine Daten",
    noMatchesText: "Keine Treffer",
    loadingDelayInMs: 200, // fast answers show no spinner at all
  },
};

Properties

autoNoRows

autoNoRows: boolean

true (default): an empty body shows "No rows to show" (or "No matching rows") by itself, after every repaint. false: only TableApi.showNoRowsOverlay shows it.

  • Defined in src/lib/table/data/options/overlay-options.if.ts:42

blockInteractionWhileLoading

blockInteractionWhileLoading: boolean

true (default): while "Loading…" is shown, mouse events on the body (click, double click, hover, context menu) are blocked and the keyboard cannot start editing or toggle rows; navigation and copying still work. false: the loading overlay is only a picture, the table stays usable. "No rows" / "No matching rows" never block.

Optional getOverlayElement

getOverlayElement?: ((kind, text) => undefined | HTMLElement)

Type declaration

    • (kind, text): undefined | HTMLElement

    • Own content of an overlay instead of the built-in one (spinner + text). Called once each time the overlay of a kind appears; return undefined to keep the built-in content for that kind. The table removes the element again when the overlay disappears or changes and in TableApi.destroy.

      The overlay is hidden from screen readers (aria-hidden, the table announces its text instead): put no buttons or links into it.

      Parameters

      • kind: GeOverlayKind

        "loading", "noRows" or "noMatches"

      • text: string

        the text the built-in content would show

      Returns undefined | HTMLElement

      the element to show, or undefined for the default

      Example

      const tableOptions: TableOptionsIf = {
        ...new TableOptions(),
        overlayOptions: {
          getOverlayElement: (kind: GeOverlayKind, text: string) => {
            if (kind !== "noRows") return undefined; // built-in spinner and texts for the others
            const div = document.createElement("div");
            div.className = "my-empty-state";
            div.textContent = `📭 ${text}`;
            return div;
          },
        },
      };
